Potencias con exponentes positivos y negativos

Propiedades, exponente cero, exponentes negativos y potencias de fracciones, con ejercicios que juntan todo lo que ya vimos.

Una potencia es una multiplicación repetida

La base es el número que se multiplica. El exponente dice cuántas veces aparece la base como factor.

Cómo se lee

$2^{3}=2\cdot 2\cdot 2=8$ base 2, exponente 3
$5^{2}=5\cdot 5=25$ «cinco al cuadrado»
$7^{1}=7$ un solo factor

El error más común

El exponente no multiplica a la base.

$2^{3}\neq 2\cdot 3$ $2^{3}=8$, no 6
$10^{4}=10\,000$ un 1 seguido de cuatro ceros
Clave: antes de calcular, escribe la multiplicación completa si dudas. Así el exponente no se confunde con un factor más.

El signo: par o impar, y dónde está el paréntesis

Base negativa entre paréntesis

Con exponente par, los signos se cancelan de dos en dos y el resultado es positivo. Con exponente impar, queda un menos suelto y el resultado es negativo.

$(-2)^{4}=(-2)(-2)(-2)(-2)=16$
$(-2)^{3}=(-2)(-2)(-2)=-8$
$(-1)^{\text{par}}=1 \qquad (-1)^{\text{impar}}=-1$

Sin paréntesis, el menos no se eleva

El exponente solo toca lo que tiene pegado. Si el menos está afuera, primero se calcula la potencia y al final se pone el signo.

$-4^{2}=-(4\cdot 4)=-16$
$(-4)^{2}=(-4)(-4)=16$
Clave: mira primero si hay paréntesis. Si lo hay, el signo entra en la potencia; si no lo hay, el signo espera afuera.

Las propiedades: misma base, se trabaja con los exponentes

Producto de igual base: se suman

$a^{m}\cdot a^{n}=a^{m+n}$
$3^{2}\cdot 3^{4}=3^{6}$ 2 + 4 = 6

Cociente de igual base: se restan

$\dfrac{a^{m}}{a^{n}}=a^{m-n}$
$\dfrac{5^{7}}{5^{3}}=5^{4}$ 7 − 3 = 4

Potencia de una potencia: se multiplican

$\left(a^{m}\right)^{n}=a^{m\cdot n}$
$\left(2^{3}\right)^{2}=2^{6}=64$ 3 · 2 = 6

Producto o cociente elevado: se reparte

$(a\cdot b)^{n}=a^{n}\cdot b^{n}$
$(2\cdot 5)^{3}=2^{3}\cdot 5^{3}=8\cdot 125=1000$
Clave: la base nunca cambia: $2^{3}\cdot 2^{4}=2^{7}$, no $4^{7}$. Y la potencia no se reparte en una suma: $(2+3)^{2}=25$, pero $2^{2}+3^{2}=13$.

Exponente cero y exponente negativo

Cada vez que el exponente baja en 1, el resultado se divide para la base. Si seguimos el patrón por debajo de cero, aparecen las fracciones.

$2^{3}=8$→$2^{2}=4$→$2^{1}=2$→$2^{0}=1$→$2^{-1}=\frac{1}{2}$→$2^{-2}=\frac{1}{4}$

En cada flecha se divide para 2.

Exponente cero: siempre 1

Un número dividido para sí mismo da 1, y en la resta de exponentes da cero.

$\dfrac{5^{3}}{5^{3}}=5^{0}=1$

Vale para cualquier base que no sea cero: $7^{0}=1$, $(-3)^{0}=1$.

Exponente negativo: se pasa abajo

El menos del exponente no vuelve negativo al resultado. Indica que la potencia va al denominador.

$a^{-n}=\dfrac{1}{a^{n}} \qquad 3^{-2}=\dfrac{1}{9}$
$10^{-3}=\dfrac{1}{1000}=0.001$ como el mili de química
Clave: $5^{-2}$ es $\frac{1}{25}$, un número positivo y pequeño. Nunca es $-25$.

Potencias de fracciones

Se eleva arriba y abajo

$\left(\dfrac{a}{b}\right)^{n}=\dfrac{a^{n}}{b^{n}}$
$\left(\dfrac{2}{3}\right)^{3}=\dfrac{8}{27}$
$\left(-\dfrac{1}{2}\right)^{3}=-\dfrac{1}{8}$ impar, queda negativo

Exponente negativo: se voltea la fracción

Primero se invierte la fracción y el exponente se vuelve positivo. El signo de la fracción se queda.

$\left(\dfrac{a}{b}\right)^{-n}=\left(\dfrac{b}{a}\right)^{n}$
$\left(\dfrac{2}{5}\right)^{-2}=\left(\dfrac{5}{2}\right)^{2}=\dfrac{25}{4}$
$\left(\dfrac{1}{3}\right)^{-1}=3$ un entero es una fracción sobre 1
Clave: un número con exponente $-1$ es su inverso: $4^{-1}=\frac{1}{4}$ y $\left(\frac{3}{7}\right)^{-1}=\frac{7}{3}$.

Cómo atacar un ejercicio combinado

El orden de siempre

( ) y [ ]→potencias→× y ÷ de izquierda a derecha→+ y − al final
$2+3\cdot 2^{-1}=2+3\cdot\dfrac{1}{2}=2+\dfrac{3}{2}=\dfrac{7}{2}$

Bases distintas: se descomponen

Las propiedades solo valen con la misma base. Si las bases son distintas, se escriben como potencias de primos.

$4=2^{2}\quad 8=2^{3}\quad 9=3^{2}\quad 12=2^{2}\cdot 3$
$\dfrac{8^{2}}{4^{3}}=\dfrac{2^{6}}{2^{6}}=1$

Sumas con exponente negativo

Primero se convierte cada potencia en fracción y luego se suma con el mcm, como en la clase de fracciones.

$2^{-1}+3^{-1}=\dfrac{1}{2}+\dfrac{1}{3}=\dfrac{5}{6}$

No es $5^{-1}$: las bases no se suman.
