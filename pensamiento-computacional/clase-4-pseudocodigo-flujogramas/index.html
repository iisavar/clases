Pseudocódigo y diagramas de flujo

Cómo se escribe un algoritmo con palabras y con símbolos, y cómo se rastrea paso a paso qué escribe.

El pseudocódigo no se ejecuta, se lee

El pseudocódigo es la descripción de un algoritmo en lenguaje natural estructurado, mezclando español con palabras clave de programación.

Palabras clave, en MAYÚSCULAS

AcciónSe escribe
Empezar y terminarINICIO … FIN
Pedir un datoLEER edad
Mostrar algoESCRIBIR "Hola"
Asignaredad ← 20
DecidirSI … ENTONCES … SINO … FIN_SI
RepetirMIENTRAS … HACER, PARA … HASTA

Área de un rectángulo

INICIO REAL base, altura, area ESCRIBIR "Ingrese la base:" LEER base ESCRIBIR "Ingrese la altura:" LEER altura area ← base * altura ESCRIBIR "El área es:", area FIN

Declaración, entrada, proceso y salida.

Clave: si area ← base * altura estuviera antes de LEER base, el cálculo se haría sin datos. El orden importa.

El diagrama de flujo dibuja el mismo algoritmo

Un diagrama de flujo o flujograma representa un algoritmo con símbolos gráficos conectados por flechas que indican el orden de ejecución.

FormaSímboloSe usa paraEjemplo
ÓvaloInicio o finINICIO, FIN
ParalelogramoEntrada o salida de datosLEER edad, ESCRIBIR area
RectánguloProceso: cálculo o asignaciónarea ← b * h
RomboDecisión: pregunta de sí o nonota >= 70
FlechaIndica el orden del flujo
Clave: el rombo es el único que divide el camino. Entra una flecha y salen dos, una para sí y otra para no.

Secuencial: una instrucción tras otra

Las instrucciones se ejecutan en el orden en que aparecen, sin saltos.

Área de un círculo

INICIO CONSTANTE PI ← 3.1416 REAL radio, area ESCRIBIR "Radio:" LEER radio area ← PI * radio * radio ESCRIBIR "Área =", area FIN

Con radio 2: 3.1416 * 2 * 2 = 12.5664

Su diagrama de flujo

Clave: LEER y ESCRIBIR van en paralelogramo. Los cálculos con ← van en rectángulo.

SI decide qué se ejecuta

Simple: SI … ENTONCES

LEER edad SI edad >= 18 ENTONCES ESCRIBIR "Eres mayor de edad" FIN_SI

Con 15 no escribe nada. Si la condición es falsa, sigue de largo.

Compuesta: SI … SINO

LEER nota SI nota >= 70 ENTONCES ESCRIBIR "Aprobado" SINO ESCRIBIR "Reprobado" FIN_SI

Con 70 escribe Aprobado, porque 70 >= 70 es verdadero.

Clave: la simple puede no hacer nada. La compuesta siempre ejecuta exactamente una de sus dos ramas.

Anidada: un SI dentro de otro SI

Se usa cuando hay más de dos casos. La sangría muestra qué SI está dentro de cuál.

LEER nota SI nota >= 90 ENTONCES ESCRIBIR "Excelente" SINO SI nota >= 70 ENTONCES ESCRIBIR "Aprobado" SINO ESCRIBIR "Reprobado" FIN_SI FIN_SI

MIENTRAS y PARA repiten acciones

MIENTRAS … HACER

i ← 1 MIENTRAS i <= 5 HACER ESCRIBIR i i ← i + 1 FIN_MIENTRAS

Revisa la condición antes de cada vuelta. Escribe 1, 2, 3, 4, 5 y sale con i = 6. Si la condición es falsa desde el inicio, no se ejecuta nada.

PARA … HASTA … HACER

PARA i ← 1 HASTA 10 HACER ESCRIBIR i FIN_PARA

Escribe del 1 al 10. Inicio, condición y avance van en una sola línea.

PARA: sabes cuántas vecesMIENTRAS: no lo sabes

Las cuatro partes de un bucle, en su diagrama

La flecha que vuelve al rombo es la repetición. Sin el incremento, i nunca llega a 6 y el ciclo no termina.

Clave: sin el incremento, i se queda en 1, la condición nunca se vuelve falsa y el bucle es infinito.
